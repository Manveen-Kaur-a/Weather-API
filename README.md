# 🌤 Weather App

A simple animated weather app built with HTML, CSS, and JavaScript using WeatherAPI.

## Features
- Live weather search
- Temperature display
- Humidity & wind details
- Animated landscape background
- Responsive UI

## Technologies
- HTML
- CSS
- JavaScript
- WeatherAPI

## Run Project
Open `index.html` in your browser.

## API
https://www.weatherapi.com/
